# Data access

The original paired-end sequencing reads are publicly available from the NCBI Sequence Read Archive under accession **SRR32633603**.

Large raw files and sample-level genomic outputs are not stored in this slim public portfolio. This includes FASTQ, SAM/BAM, VCF, GDS, reference FASTA, and large annotation files. They can be regenerated using the commands in `workflow/full_pipeline_template.sh`.

The repository provides summary metrics, curated figures, scripts, and workflow documentation to demonstrate the analysis.

See `DATASET.md` at the repository root for attribution and access details.
