# Limitations

- The analysis represents one sample, so cohort-level statistics and association testing are not possible.
- Several VCF contig labels are target-region coordinates rather than standard chromosome names.
- The raw FASTQ, aligned BAM, reference FASTA, and full preprocessing commands were not supplied.
- The small annotation CSV is incomplete and should not be treated as a comprehensive functional annotation.
- Some original R scripts use simulated SNP data for visualization practice; these are separated from real-VCF evidence.
- PCA is not biologically informative for a single sample.
- Variant calls have not been clinically validated and must not be used for diagnosis or treatment decisions.
