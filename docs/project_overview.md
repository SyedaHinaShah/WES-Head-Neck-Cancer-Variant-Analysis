# Project overview

## Research objective

This project documents an independent reanalysis of publicly available sequencing data from NCBI SRA run `SRR32633603`. It demonstrates the movement from raw paired-end reads through quality control, fastp preprocessing, alignment and SAM/BAM handling, GATK variant calling and filtering, and downstream R/Python analysis.

## Personal contribution

Syeda Hina Shah independently downloaded the public data and performed the computational workflow, including FastQC, fastp, BWA alignment, SAMtools-based processing, GATK variant calling and hard filtering, downstream analysis, visualization, interpretation, repository organization, portfolio preparation, and presentation design.

The original sequencing data were generated by the investigators associated with the NCBI SRA record; they were not generated by the repository author.

## Main outcome

The project demonstrates practical skills in Linux bioinformatics, reproducible analysis, variant-file interpretation, scientific visualization, transparent limitations, and professional research communication. It is a research-training project rather than a clinical diagnostic analysis.
